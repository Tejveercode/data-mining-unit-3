## Method (identical to Unit 2)

1. **Extract** each LMS page to plain text, keeping its own headings, definitions and worked examples.
2. **Write one note per LMS topic**, in LMS order — the page's examples are completed, not replaced.
3. **Verify every number** by actually running the algorithm (Apriori counting, tree construction, distance calculations, cluster assignments), so nothing in the notes is hand-waved.
4. **Flag any error or omission in the source page** diplomatically, and show the correct working.
5. **Build the exam pack**: revision cheat sheet + question bank with model answers.
6. **Implement it in code**, so each algorithm can be run and inspected.
7. **Generate PDFs** for printing.
